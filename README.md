# HD - Vite React SPA Migration

Dieses Repository wurde teilweise in eine Vite + React Single-Page-App migriert. Ziel: bestehende Seiten (außer `ob/`) über eine SPA verfügbar machen und die interaktiven Bestandteile schrittweise in React konvertieren.

Quick start:

1. Install dependencies:

```bash
npm install
```

2. Development server:

```bash
npm run dev
```

3. Build:

```bash
npm run build
```

4. Preview production build:

```bash
npm run preview
```

Hinweis: Legacy-Seiten (z. B. `games/bartclicker.html`) werden vorerst per iframe eingebunden. Für vollständige React-Migration schaue in `MIGRATION.md`.
